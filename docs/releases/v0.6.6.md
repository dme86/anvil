# Anvil v0.6.6 — a bar that gets out of the way

This release polishes Anvil's built-in status bar and gives the project a clearer, friendlier README.

- **Super+B toggles the built-in bar** on all connected monitors. Hidden bars no longer reserve space or intercept bar clicks; ordinary windows can expand into the freed area. Bar visibility stays consistent across output hotplug and config reloads.
- **Larger Nerd Font glyphs without larger text:** optional `[bar].icon_size = 19.0` renders private-use icons at their own size while keeping `font_size` unchanged. Glyph advances use matching sizes, so text and hit targets do not overlap. Default behavior is unchanged if `icon_size` is omitted.
- **Reload-friendly appearance:** changing the numeric icon size works with `anvilctl reload`. Changing `bar.font` still requires a compositor restart.
- **README refresh:** quick introduction, selling points, build variants, sample shell blocks, keyboard shortcuts, aarch64 notes, and links to deeper documentation.

### Suggested settings

```toml
[bar]
height = 26
font = "JetBrainsMono Nerd Font Mono"
font_size = 14.0
icon_size = 19.0

[keys]
toggle_bar = "b"
```

`icon_size` applies to Unicode private-use glyphs used by Nerd Fonts, not regular letters or color emoji. Install a font that includes the symbols you use in shell blocks. Larger icons may require a taller bar.

### Install

Get the binary matching your CPU architecture from [the releases page](https://github.com/dme86/anvil/releases); if a prebuilt artifact for your system is unavailable, build locally with `cargo build --release --locked`.

### Test coverage

The version is checked by GitHub Actions for Rust formatting, all-feature tests, Clippy, bar-free builds, nested Wayland protocols, and footprint profiles. Real DRM hotplug/session behavior must also be verified on physical hardware.
