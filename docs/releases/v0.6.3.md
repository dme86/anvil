# Anvil v0.6.3 — XWayland window mapping reliability

This patch release addresses an intermittent XWayland integration failure where a live X11 window could be absent from Anvil's managed window list even though the XWayland server had started successfully.

## Fix

- Handle Smithay's X11 `map_window_notify` callback in the compositor and forward it through the event-loop state.
- Register newly mapped X11 windows once the associated Wayland surface exists, even when the association arrives around the X11 map request.
- Keep X11 registration idempotent and retain the existing late-surface-association path.
- Preserve the real XWayland crash/recovery CI test rather than skipping or weakening it.

The change is confined to the optional XWayland integration. Native Wayland workflows and default feature selection are unchanged.

## Installation

As with previous releases, the x86_64 Linux archive includes `anvil`, `anvilctl`, configuration and session files, documentation, and notices. Verify the provided SHA256 checksum.
