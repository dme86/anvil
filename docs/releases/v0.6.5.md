# Anvil v0.6.5 — asynchronous status blocks

This release brings dwmblocks-async-style shell modules to Anvil's built-in bar.

- Declare any number of independent status commands (up to 16) using `[[bar.blocks]]` in `config.toml`, each with a name, command and interval in seconds plus an optional timeout.
- Commands execute in bounded background workers, not the compositor event loop; results are delivered through Calloop notifications and coalesced repaint requests.
- Cache the last successful output, skip overlapping runs, reject oversized output and ignore stale worker results after `anvilctl reload`.
- Preserve the old `[bar].status_commands` configuration, now also executed asynchronously. New named blocks supersede the legacy list.
- Include sample scripts for Gentoo Portage updates, network, weather, battery and kernel status in `scripts/bar/`. The Gentoo script never automatically syncs repositories or runs sudo.
- Add config examples, operator documentation and unit/shell regression tests.

### Example

```toml
[[bar.blocks]]
name = "updates"
command = "bash ~/.config/anvil/scripts/gentoo_updates.sh"
interval = 3600
timeout = 60

[[bar.blocks]]
name = "clock"
command = "date '+%H:%M'"
interval = 60
```

For setup, safety limits and migration guidance see [docs/async-bar-blocks.md](../async-bar-blocks.md).

**Requirements:** GNU coreutils `timeout` must be installed for script workers; Bash is needed for the included example scripts. Runtime remains independently optional through the existing `bar` Cargo feature.
