# Anvil v0.6.9 — refresh status blocks when something changes

Your status bar can now react to external events (package upgrades, hooks, interactive commands), without adding a poller or another permanent daemon.

## New commands

```sh
anvilctl bar refresh updates
anvilctl bar refresh --all
```

- Resolves **unique, case-sensitive names** from the running compositor's validated `[[bar.blocks]]` TOML configuration.
- Ignores each block's interval for explicit refresh requests without changing its normal schedule. The IPC response acknowledges scheduling (started/queued), not completion.
- Keeps jobs **asynchronous and bounded**: no overlapping execution of the same block; multiple requests received while running coalesce into **one** follow-up job. Script timeouts, output limits and successful-output caching remain intact.
- One invocation updates the **shared status cache on all monitors**. Hidden bars update their cached text without unnecessary rendering; hotplugged outputs see the latest result.
- `--all` supports legacy `status_commands`, while a named refresh requires `[[bar.blocks]]`. Unknown names are rejected; no arbitrary command execution via IPC.
- Both `bar+anvilctl` and minimal `anvilctl`-only builds are supported (the latter returns a clear unsupported response).
- The documented Arch pacman hook uses a fixed, explicitly trusted user with `runuser` and that user's `XDG_RUNTIME_DIR`. The Anvil IPC socket remains mode `0600`.

See [the async bar blocks guide](../async-bar-blocks.md) for configuration and hook examples.

## Resource impact

No additional idle timers, permanent threads, per-monitor subprocesses or automatic polling were added. New child threads are launched only on a scheduled or explicitly requested refresh, with one queued rerun maximum per block. GitHub CI runs Rust tests, CLI IPC tests, nested Wayland protocol tests and footprint measurement profiles.

## Installation

Use the matching release binary where available, or on Gentoo aarch64 build locally using `cargo build --release --locked` and install the binary before restarting Anvil.
