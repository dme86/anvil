# Anvil v0.6.0 — Session-wide Window Overview

Anvil v0.6.0 adds a compositor-native **window overview**, inspired by Exposé/Mission Control but designed for a keyboard-driven, dwm-style Wayland desktop.

Press **Super+Tab** to show one central overview on the **currently focused monitor**. It includes each individually managed window from **all connected monitors and all tags**, without moving, resizing, remapping or changing the active tags. Preview content comes from the clients' existing Wayland/XWayland buffers.

## What's new

### 1. Visual overview of the entire session ([#29](https://github.com/dme86/anvil/issues/29), [PR #54](https://github.com/dme86/anvil/pull/54))

- Scaled, aspect-ratio-preserving window previews rendered independently of the normal visible-window `Space`.
- Works with tiled, floating and hidden-tag windows, including XWayland when enabled.
- The overview appears on the focused output only; other monitors retain their ordinary desktop.
- **Escape** or **Super+Tab** closes the overview without changing workspace selection or keyboard focus.
- Built through the optional, default-enabled `overview` Cargo feature; minimal builds can omit it with `--no-default-features`.

### 2. Keyboard navigation and direct activation ([#30](https://github.com/dme86/anvil/issues/30), [PR #55](https://github.com/dme86/anvil/pull/55))

- Move the highlighted window with **arrow keys** (and configured previous/next focus shortcuts).
- Press **Enter** or **left-click** an individual preview to activate it.
- Activation switches to the selected window's original monitor and tag, then focuses it using Anvil's existing activation and layout logic.
- Selection follows each window's identity, remaining stable when another window closes.
- Cancelling leaves the session unchanged.

### 3. Monitor → Tag → Application organization ([#31](https://github.com/dme86/anvil/issues/31), [PR #56](https://github.com/dme86/anvil/pull/56))

- Window cards are organized under distinct **output/monitor and numbered tag** headings, then **application** headings based on `app_id`.
- Each window keeps its **own thumbnail and individual title**; instances are never collapsed into a single application entry.
- A multi-tag window appears once under its lowest numbered tag, while the card shows all its tag memberships.
- Sections use stable output, tag and application ordering; card navigation follows the grouped layout.
- Grid columns adapt to monitor size. Crowded sessions use **numbered pages** with full-size, selectable cards rather than unreadably tiny previews; navigating to a window automatically switches to its page.
- Missing application IDs and unassigned tags have readable fallback labels.

## Quick start

```sh
# Default features include the overview.
cargo build --release

# Open: Super+Tab
# Navigate: arrow keys
# Activate: Enter or left-click a preview
# Cancel: Escape or Super+Tab
```

Configure the shortcut in your `config.toml`:

```toml
[keys]
overview = "Tab"
```

The overview shows the last available contents of each window. Applications on hidden tags may stop committing new frames while hidden; their thumbnails are therefore not guaranteed to animate. All previews are handled inside Anvil: no external overview daemon is required.

## Installation

The x86_64 Linux release archive includes `anvil`, `anvilctl`, the sample configuration, Wayland session desktop file, README, license and notices. Verify the archive with the accompanying `.sha256` checksum.

**Validation:** The Rust build, Clippy, nested Wayland protocol tests (including XWayland when enabled), and size/feature-profile checks are exercised by GitHub Actions. Physical DRM/KMS validation is still tracked separately in [#47](https://github.com/dme86/anvil/issues/47); this remains a pre-1.0 release.
